# FixIt – Campus Complaint Management Portal

## Project Overview
FixIt is a web-based campus complaint management portal designed to make reporting and tracking campus-related issues easier for students. It provides a central platform where students can submit complaints and staff can review and update their status.

## Problem Statement
Traditional complaint processes can be difficult to track and manage. Students may not know the current status of their complaints, while staff may find it difficult to organise and monitor reported issues.

## Proposed Solution
FixIt provides a centralised online platform for submitting complaints, viewing previously reported issues, and managing complaint statuses through a staff dashboard.

## Key Features
- Student complaint submission form
- Input validation
- Optional photo attachment
- My Issues page
- Individual complaint details
- Staff login and session management
- Staff dashboard
- Complaint filtering
- Dashboard summary cards and pie chart
- Complaint status updates

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** TiDB Cloud (MySQL-compatible)
- **ORM:** Flask-SQLAlchemy
- **Database Driver:** PyMySQL
- **Deployment:** Render
- **Version Control:** Git and GitHub

## Complaint Statuses
- Reported
- In Progress
- Resolved
- Closed
